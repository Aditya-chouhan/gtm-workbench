# GTM Workbench product facts

Source: this repository's implementation and tests, October 29, 2026.
GTM Workbench is an MIT-licensed local Python CLI for task contracts, dependency
tracking, Markdown handoffs, artifact snapshots, review fingerprints and audit events.
It works with manually supplied assistant output. Source/dependency changes can
make downstream reviewed work stale. It has no CRM, email or publishing connector,
no autonomous model runtime and no measured customer performance evidence.

Research question: would a technically sophisticated marketing team be a useful
discovery audience? This is exploratory research, not evidence of buying intent.
