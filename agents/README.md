# Agent contracts

These are reusable role instructions for your assistant. They are not running agents or tool permission settings. Use only roles needed for the current task graph.

- [Coordinator](coordinator.md): Turn a stated business goal into the smallest useful graph of reviewable tasks.
- [Researcher](researcher.md): Assemble a small, auditable evidence bundle for a concrete GTM question.
- [Account Analyst](account-analyst.md): Decide which supplied accounts fit a declared ICP and why.
- [Outreach Writer](outreach-writer.md): Draft a relevant first touch or follow-up from supplied account facts.
- [Campaign Reviewer](campaign-reviewer.md): Assess whether supplied audience and copy are ready for the proposed pilot.
- [Conversation Analyst](conversation-analyst.md): Classify supplied replies and past deal conversations, then propose a grounded response.
- [Content Editor](content-editor.md): Create useful editorial briefs grounded in audience questions and available proof.
- [Content Producer](content-producer.md): Produce channel-specific drafts and editable asset briefs from an editorial brief.
- [Experiment Analyst](experiment-analyst.md): Compare observed outcomes with a decision rule and recommend the next change.

The CLI embeds each role's short mission in a handoff. Load the corresponding file here when you want the fuller working guidance.
